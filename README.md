# Параметры запуска

| Флаг | Переменная окружения | Назначение | По умолчанию |
| --- | --- | --- | --- |
| `-a` | `RUN_ADDRESS` | Адрес HTTP-сервера в формате `host:port` | `localhost:8080` |
| `-d` | `DATABASE_DSN` (`DATABASE_URI` для совместимости) | Строка подключения к PostgreSQL | Обязательный параметр |
| `-r` | `ACCRUAL_SYSTEM_ADDRESS` | HTTP/HTTPS-адрес сервиса начислений | Обязательный параметр |
| — | `JWT_SECRET` | Секрет подписи JWT: случайное значение минимум 32 байта | Обязательный параметр |

Приоритет: явно заданный флаг → переменная окружения → значение по умолчанию. Для БД: `-d` → `DATABASE_DSN` → `DATABASE_URI`.
`JWT_SECRET` задаётся только через окружение и должен сохраняться между запусками.
Справка: `go run ./cmd/gophermart -h`.
