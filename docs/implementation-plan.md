# План реализации Гофермарта

Учебный план разработки HTTP API накопительной системы лояльности на Go. Основной код пишет разработчик; ментор помогает с проектированием, разбирает трудности и проводит ревью. Каждый этап завершается работающей частью сервиса, проверками и ревью.

Подготовка среды описана в [памятке](development-memo.md). Рабочий репозиторий — папка gophermart. PostgreSQL запускается через Podman, Go-приложение — в Windows. Репозиторий: C:\Users\suslov-andrey\Desktop\gophermart.

## Начальная структура

```text
cmd/gophermart/       запуск приложения
internal/config/     настройки
internal/handler/    HTTP и middleware
internal/service/    бизнес-правила
internal/storage/    PostgreSQL
internal/accrual/    клиент и обработка начислений
migrations/          схема базы
```

Создавать пакеты по мере необходимости. Интерфейсы вводить для независимых тестов и границ компонентов, без отдельного интерфейса на каждую структуру.
